# Журнал экспериментов Практики 2

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Выбранный слабый артефакт Практики 1: [`tests_e2e.md`](../practice_01/tests_e2e.md), сценарий **E5** («Реальная выбранная модель...»).
- Что в нём нужно улучшить: строка E5 описывает проверку качества AI-ревью слишком обобщённо — нет фиксированных входов с хешами, нет явных pass/fail критериев на каждое утверждение из R7, нет формы отчёта и порядка сохранения результатов. Формулировки «недоказанных утверждений» и «инъекционный вариант» не операционализированы (кто и как проверяет, какой шаблон отчёта).
- Как поймём, что изменение полезно: после правки другой инженер сможет провести E5 без уточняющих вопросов — по фиксированным входам (с хешами), пройти по чек-листу pass/fail для каждого критерия R7 и заполнить одинаковый по структуре отчёт; результат проверки воспроизводим и не требует уточнений у автора.
