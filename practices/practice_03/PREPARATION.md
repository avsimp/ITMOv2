# До занятия

Подготовку выполняйте с OpenCode в режиме Build. Агент проверяет окружение, выполняет команды и ведёт `REPORT.md`. Вы выбираете предложенную конфигурацию и помогаете только там, где установка требует действий в интерфейсе системы. Markdown и конфигурации вручную редактировать не нужно.

За день до практики: освободите место, установите инструменты, скачайте модель и выполните первый запрос. Скачивание не входит в 90 минут.

## Инструменты

- [Ollama](https://ollama.com/download): актуальная версия с поддержкой выбранной модели. Старый runtime может не понимать новую архитектуру.
- [OpenCode](https://opencode.ai/docs/): установка по официальной инструкции.
- Python 3.10+ для учебного репозитория, curl, make.
- Windows: основной CLI-маршрут через WSL. Желательно запускать Ollama и OpenCode в одной среде. Если Ollama в Windows, а OpenCode в WSL, localhost может указывать на разные серверы. Сначала проверьте API.
- LM Studio допустим по инструкции в конце практики.

## Выбор модели

Начните с варианта для своего устройства и проверьте расход памяти при запуске:
| Доступное устройство | Начало эксперимента |
|---|---|
| 8 GB RAM, CPU | qwen3.5:0.8b или qwen3.5:2b, контекст 4096 |
| 16 GB RAM | qwen3.5:4b, контекст 4096 |
| 24–32 GB RAM | qwen3.5:4b или :9b, затем проверка 64k |
| Дискретная GPU | Сначала оценить свободную VRAM, затем RAM и offload |

Каталог Ollama указывает около 1.0/2.7/3.4/6.6 GB для весов 0.8B/2B/4B/9B. Это размер загрузки, не пиковая память. Теги могут обновляться: поручите агенту записать ID из `ollama list` и вывод `ollama show`.

```bash
ollama --version
opencode --version
ollama pull qwen3.5:4b
ollama run qwen3.5:4b "Объясни разницу между моделью и сервером двумя предложениями"
```

Если выбрали меньшую модель, поручите OpenCode согласованно заменить тег в командах и `FROM` в обоих Modelfile.
Попросите рабочего агента задать локальной модели вопрос: «Объясни разницу между моделью и сервером двумя предложениями» и сохранить ответ.

```bash
curl --fail http://localhost:11434/api/tags
ollama list
ollama show qwen3.5:4b
```

Сервер обычно запускает приложение Ollama. Если он не запущен, попросите OpenCode запустить `ollama serve` отдельным процессом. Не запускайте второй сервер на занятом порту.

## Проверка работы без облака

Выбирайте скачанную модель без суффикса cloud. Для занятия отключите cloud-функции Ollama через OLLAMA_NO_CLOUD=1 в окружении серверного процесса и перезапустите его. Учтите, что приложение из меню может не наследовать переменную вашего терминала. После загрузки весов и зависимостей повторите запрос без интернета. Отключите внешние MCP и плагины в учебном OpenCode, если они настроены глобально.

## До прихода в аудиторию

Сравните карточки двух моделей разных разработчиков, например Qwen и Gemma или Phi. Попросите OpenCode записать для каждой задачу, число параметров, формат, лицензию, поддержку русского языка и tool calling. Если карточка не обещает возможность, отметьте «не подтверждено». Скачивать обе модели не обязательно.

Поручите OpenCode записать в отчёт RAM, CPU/GPU, свободную VRAM (если есть), ОС, версии, модель, размер весов и результат первого запроса.
Если запуск не удался, OpenCode сохраняет текст ошибки. Для OpenCode при нехватке памяти предусмотрена работа в паре на локальном компьютере партнёра.
