## Ограничения

- `REPORT.md` описывает прежний код с тремя тестами и без `unsubscribe`.
  Это история эксперимента, а не описание текущего API; старые ответы
  модели нельзя считать новым прогоном актуальных вопросов.
- По историческим результатам локальный агент иногда давал пустой видимый
  ответ или ошибался при поиске. Причина пустого ответа не установлена;
  правка инструкций не устранила проблему полностью. В этой сессии модель
  не запускалась, её текущая доступность не проверена.
- Сохранять старые результаты; новые запуски размещать отдельно.
  Тестируемой модели разрешено только чтение; эталоны, отчёт и этот handoff
  не передавать в её контекст.
- Перед изменением Python-кода прочитать `STYLE_GUIDE.md` и применить
  `notify-mini-development`; для экспериментов — `practice-03-local-models`.
  Не переключать ветку и не создавать коммит без запроса пользователя.
