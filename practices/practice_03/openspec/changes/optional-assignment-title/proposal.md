# Proposal

## Why

Преподавателю нужен необязательный заголовок в PDF домашней работы, без ручного изменения готового документа. Этот change — черновик для проверки правил OpenSpec; текущий запрос разрешает подготовку документов, но не реализацию.

## What Changes

- Предлагается необязательная строка `title` у `create_pdf`, по умолчанию `""`; прежний вызов с ID и путём продолжает работать.
- Явно переданный непустой заголовок отображается один раз перед первым пунктом как обычный текст, без интерпретации HTML. Пустой и пробельный заголовок не добавляет элементов или отступов.
- Без заголовка сохраняются прежние оформление и поведение экспорта, включая PDF/ZIP, ответы, sources, ссылки и запрет перезаписи.
- Сохраняются порядок и исходные условия задач, нумерация приложений и правило «19–21 — один пункт». Заголовок не считается пунктом домашней работы.
- Уточняется существующий запрет заголовков: исключением становится только явно заданный заголовок работы; добавление ответов и номеров страниц по-прежнему запрещено.
- Проверки и документация будущей реализации отражают необязательный аргумент и совместимость старых вызовов.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `homework-delivery`: необязательный заголовок PDF и совместимое расширение аргументов экспорта; сохранение прежнего результата при отсутствии заголовка.

## Impact

- Будущие точки изменения: `homework/server.py` — аргумент MCP; `homework/render.py` — передача и вставка экранированного текста в HTML перед задачами.
- Проверки: `homework/tests/test_export.py` — сейчас MCP-тест фиксирует ровно два свойства входной схемы, его нужно расширить, сохранив два обязательных аргумента.
- Документация будущей реализации: `homework/README.md`, описание инструмента и `homework/.opencode/skills/compose-assignment/SKILL.md`, где сейчас указан формат без заголовков.
- Новые библиотеки, новые инструменты MCP, настройки шрифтов, шаблоны, колонтитулы, автоматическое сочинение заголовка, переименование файлов и изменение формата ответа не требуются.
- Реализация, тесты приложения и основные спецификации в рамках этого запроса не изменяются. Предложенные значения по умолчанию и оформление описаны в design для ревью черновика.
