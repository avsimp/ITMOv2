# Диагностика

Передайте ошибку рабочему агенту OpenCode. Он выполняет проверки из таблицы, исправляет конфигурацию и записывает результат в отчёт. Ограниченный агент `local-guide` для настройки окружения не используется.

| Симптом | Проверка | Действие |
|---|---|---|
| Connection refused | GET /api/tags | Запустить единственный сервер Ollama |
| Address already in use | Проверить запущенное приложение | Использовать существующий сервер |
| Неизвестная архитектура | Версия Ollama и карточка модели | Обновить runtime, повторить pull |
| 404 model not found | ollama list, ollama show | Исправить точный тег или выполнить create |
| Очень медленно | ollama ps, память, холодный старт | Уменьшить модель, закрыть приложения, отделить загрузку |
| OOM после подключения агента | Контекст 64k, RAM/VRAM | Более маленькая модель или локальная машина партнёра |
| Чат работает, tools нет | Реальные события read | Проверить поддержку tools, chat template и runtime |
| JSON вместо действия | Возврат tool_calls сервером | Сменить совместимую модель/формат, ограничить задачу |
| SYSTEM будто игнорируется | Где задан system: GUI/API/agent | Передать инструкцию на уровне используемого клиента |
| Выдуманные файлы | Сопоставить с результатом read | Поручить рабочему агенту проверить источники и уточнить prompt |
| WSL не видит сервер Windows | Среда и localhost | Разместить оба инструмента в одной среде |
| Агент ушёл в облако | Точный provider/model и плагины | Выбрать локальный ID, отключить внешние подключения |

Нельзя исправить нехватку весовой памяти одним сокращением ответа. Снижение контекста может помочь с cache, но не уменьшает веса.
