# Notify Mini
Учебный сервис подписки. Подписчики хранятся в памяти процесса.
В service.py функция subscribe добавляет непустое имя в множество.
Повторное добавление имени не создаёт дубликат.

Проверка: make test.
Зависимости: стандартная библиотека Python 3.10+.

## Подписка и отписка

Функции находятся в `service.py` и принимают строковое имя:

- `subscribe(name)` добавляет подписчика и возвращает `{"subscribed": True}`, в том числе при повторной подписке.
- `unsubscribe(name)` удаляет подписчика и возвращает `{"unsubscribed": True}`, если имя было в множестве. Для неизвестного имени или повторной отписки возвращает `{"unsubscribed": False}`. Остальные подписчики сохраняются.

Обе функции удаляют пробелы по краям имени с помощью `strip()`. Пустая строка или строка только из пробельных символов вызывает `ValueError("empty name")` без изменения подписчиков. Регистр учитывается: `Ann` и `ann` — разные имена.

```python
from service import subscribe, unsubscribe

subscribe("Ann")       # {"subscribed": True}
unsubscribe(" Ann ")   # {"unsubscribed": True}
unsubscribe("Ann")     # {"unsubscribed": False}
```

## Просмотр подписчиков (фича B)

`list_subscribers()` в `service.py` вызывается без аргументов и возвращает
новый список текущих подписчиков. Для пустого множества результат — `[]`.
Имена уникальны, уже очищены от пробелов при подписке и сохраняют регистр.
Порядок — стандартная сортировка строк Python (по Unicode, с учётом регистра),
а не порядок добавления или локализованный алфавитный порядок.

Чтение не меняет подписки и не вызывает ошибок при пустом множестве.
Каждый вызов возвращает независимый снимок: изменение списка не меняет
подписки, а последующие подписки и отписки не меняют ранее полученный список.
Новый вызов отражает актуальное состояние в памяти процесса.

```python
from service import list_subscribers, subscribe, unsubscribe

# Пример для изначально пустого множества подписчиков.
subscribe(" Bob ")
subscribe("Ann")
snapshot = list_subscribers()  # ["Ann", "Bob"]
unsubscribe("Ann")
list_subscribers()            # ["Bob"]
# snapshot по-прежнему равен ["Ann", "Bob"].
```
