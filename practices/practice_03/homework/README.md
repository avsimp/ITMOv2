# Подбор задач для репетитора

**Skill `compose-assignment` + MCP `polyakov`**: задачи ЕГЭ по информатике
с сайта К. Полякова, подбор по запросу преподавателя и PDF с постоянной вёрсткой.
Весь проект находится в этой папке и переносится вместе с ней.

## Использование

На этом компьютере окружение и Chromium уже установлены. Из папки практики:

```bash
opencode ./homework
```

Заверши старую сессию OpenCode и запусти новую: конфигурация MCP и список skills
подхватываются при запуске. Запускай именно с рабочей папкой `homework`, поскольку
команда MCP в `opencode.json` использует относительные пути.

Пример сообщения:

> Используй compose-assignment. Составь 5 задач № 1 на сопоставление графа и
> таблицы и 5 задач № 5 на биты чётности. Средняя сложность, две задачи чуть
> сложнее. На уроке были 9048 и 9073 — исключи их.
> Сохрани в ~/Documents/lessons/подборка.pdf.

Для игр:

> Составь домашку из 10 блоков 19–21 только на одну кучу. Восемь похожих на
> задачу 9175, две немного сложнее. Саму 9175 исключи.
> Сохрани в ~/Documents/lessons/задание 19-21/домашняя работа.pdf.

Путь из твоего прежнего примера не использовался для тестовых файлов.
Если путь не указан, skill выбирает новое имя в `output/`.

### Формат результата

- PDF: только `1)`, `2)` и условия с рисунками и таблицами.
- A4, поля 18 мм, основной шрифт 12 pt, без заголовка и номеров страниц.
- Обычная задача — один пункт. Для 19–21 **весь блок из трёх вопросов — один пункт**.
- Ответы отдельно в сообщении и `.answers.txt`, источники в `.sources.json`.
- Обычный ответ: `1. 22`. Тройка: `1. 19) 41; 20) 36 40; 21) 35`.
- При наличии исходных файлов они скачиваются в соседнюю папку `.files`:
  её нужно передать ученику вместе с PDF. Ответы и sources предназначены тебе.
- Существующая подборка не перезаписывается: для повторного экспорта нужно новое имя.

Вёрстка задаётся кодом `render.py`, а не каждый раз моделью. `create_pdf`
принимает **только ID**, самостоятельно загружает условия и ответы по ним.
Модель не может передать в этот инструмент сочинённое или изменённое условие.
Текст и авторские пометки внутри исходного условия сохраняются.

## Установка на другом компьютере

Нужны Python 3.11+ и OpenCode. Команды из этой папки:

```bash
make setup
opencode mcp list
opencode
```

Для разработки и проверки:

```bash
make setup-dev
make check
make demo
```

На Linux для Chromium могут потребоваться системные зависимости Playwright.
Основные версии библиотек зафиксированы в `requirements.txt`; текущее рабочее
окружение — macOS, Python 3.14.4. Виртуальное окружение не переносится: создаётся заново.

## Что делает MCP

| Tool | Назначение |
|---|---|
| `list_categories(ege_number)` | Актуальные категории выбранного номера КИМ |
| `search_tasks(...)` | Полные условия и ответы, категории, подстрока, исключения, пагинация |
| `get_task(topic_id)` | Одна задача по постоянному ID генератора |
| `create_pdf(topic_ids, output_path)` | Фиксированная вёрстка, ответы, источники и приложения |

Примеры аргументов:

```json
{"ege_number": 1, "category_ids": [12, 13], "limit": 5}
```

```json
{"ege_number": 5, "category_ids": [28], "exclude_ids": [9073], "limit": 10}
```

```json
{"ege_number": 19, "category_ids": [163], "limit": 10, "offset": 0}
```

Сложность — оценка агента по оригинальному условию и примерам с урока.
Сайт не предоставляет используемую нами шкалу «легко / средне / сложно».
`contains` — только поиск подстроки. Для графов skill требует смотреть рисунки.

## Как устроена адресация Полякова

Исследованы HTML и JavaScript страницы
<https://kpolyakov.spb.ru/school/ege/generate.htm>.

1. Категории: `gen.php?action=listCategories&egeId=5` → JSON с `id` и `title`.
2. Список: `gen.php?action=viewAllEgeNo&egeId=5&cat27=on&cat28=on&cat144=on`.
   `egeId` — номер КИМ, `cat...=on` — выбранные подтипы.
3. Одна задача: `gen.php?action=viewTopic&topicId=9080`.
   ID базы генератора не равен порядковому номеру в DOC-сборнике.
4. Условие лежит в `td.topicview` внутри
   `document.write(changeImageFilePath('...'))`.
5. Ответ — в следующей строке, `div.hidedata` с ID этой задачи.
   Кнопка «Показать ответ» лишь переключает видимость: отдельного запроса нет.
6. Префиксы изображений и файлов берутся из `#imagePath` и `#filePath`.
   Обычно это `/cms/images/` и `/cms/files/`. Начальный `:` в исходной ссылке
   означает, что префикс добавлять не надо — это правило JavaScript сайта.
7. Для 19–21 сайт уже хранит общую игру и три вопроса в одной записи.
   Используется `egeId=19`; категория 163 — одна куча, 154 — две, 171 — три.
   Перед подбором категории запрашиваются заново.

JavaScript сайта не исполняется: извлекаются только строковые литералы через
JSON5. HTML условий сохраняется для индексов, таблиц и иллюстраций. Chromium
нужен только для локальной печати PDF. Изображения предварительно загружаются
и встраиваются в документ. HTTP-ответы кешируются в памяти процесса на 15 минут.

## Проверки и ограничения

`verify_live.py` запускает настоящий MCP-сервер отдельным процессом и вызывает
инструменты через stdio. Каждый запуск создаёт новый `output/run-*` с JSON-логом,
PDF, ответами, источниками и изображениями страниц. Успех проверяется по ответу
протокола, ошибочные сценарии — по `isError=true`.

Проверены категории и подборы № 1, 5 и 19–21; экспорт графа, числового алгоритма
и игры; отдельно получение файла электронной таблицы. Остальные номера доступны
через общие инструменты, но все задачи банка и все варианты их разметки не проверены.
Изменение HTML сайта может потребовать обновления парсера; вместо незаметно
неполной задачи он возвращает ошибку. Ресурсы за пределами домена Полякова
не подменяются: такой экспорт останавливается с объяснением.

Автоматические проверки не заменяют визуальный просмотр каждой новой подборки.
Ключ копируется с сайта, а не доказывается решателем. Реальная экономия времени
и качество подбора сложности пока не измерялись на занятиях.

## Файлы

- `.opencode/skills/compose-assignment/SKILL.md` — рабочий процесс репетитора.
- `opencode.json`, `server.py` — подключение и инструменты MCP.
- `polyakov.py` — получение и разбор данных источника.
- `render.py` — единое оформление PDF и отдельных ответов.
- `tests/test_bank.py` — автономные регрессионные тесты.
- `verify_live.py` — воспроизводимое живое демо через MCP.
- `VERIFICATION.md` — фактические результаты и технические наблюдения.
- `reflection.md` — краткая личная рефлексия.
- `evidence/` — сохранённые запросы и ответы MCP, примеры PDF и сопутствующие файлы для сдачи.
