# Рефлексия

В этой работе я настроил правила для агента, skill и свой MCP для подбора задач ЕГЭ. Самым сложным оказался разбор сайта: условия и ответы хранятся внутри JavaScript. Для PDF сделал единый шаблон, чтобы оформление не зависело от модели. Проверки показали, что MCP выдаёт результат и обрабатывает ошибочные запросы, а hook останавливает коммит с ошибкой в тестах.
