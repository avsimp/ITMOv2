# Воспроизведение ДЗ 6

Требования: Python 3.10+, Git и OpenCode с доступом к модели
`openai/gpt-6.1-sol` (использована в сохранённом эксперименте).
`shop-planner` и `threat-judge` настроены в `opencode.json` без доступа к инструментам.
Доступ модели проверяется через обычную авторизацию OpenCode; ключи в репозитории отсутствуют.

Из корня форка:

```bash
python3 -B practices/practice_06/lab/reproduce.py
make step6
make test
```

`reproduce.py` получает исходный `service.py` из коммита `0c8a9c1` через
`git show`, сохраняет во временный каталог и передаёт его обоим проверяющим
скриптам через `--service`. Рабочий исправленный файл не заменяется. Для тестов
создаётся отдельная копия стенда с выбранной версией сервиса. Падение security-тестов
в before-фазе ожидаемо; полный результат и exit code сохраняются в evidence.

Для проверки HTTP без запуска моделей:

```bash
python3 -B practices/practice_06/lab/reproduce.py --http-only
```

Полный запуск обновляет `evidence/before/`, `evidence/after/` и `evidence/judge/`.
Каждая фаза создаёт чистый локальный магазин с синтетическими данными.
Проверка модели использует две новые сессии OpenCode: обычный контекст и тот же
контекст с вредоносным отзывом. Сохраняются точный контекст, пользовательская
задача, хэш системного промпта, финальные ответы и результаты исполнителя.
Внутренние рассуждения не сохраняются. Принудительные опасные решения проверяются
отдельно от решений реальной модели. Исходный эксперимент с прямым вызовом Ollama
сохранён как дополнительный материал в `evidence/ollama/`.

Можно выбрать другую подключённую модель через `--model provider/model`; для
сравнимости обе фазы одного эксперимента должны использовать одну модель.

Дополнительно настроен локальный провайдер Ollama. Для него предварительно
запустите `ollama serve` и используйте `--model ollama/qwen3.5:9b`.
Этот вариант не требуется для повторения сохранённого основного эксперимента.
