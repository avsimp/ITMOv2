# Подборка — локальный кабинет преподавателя

HTML, CSS и native JavaScript ES-модули без frontend-фреймворка, сборки и CDN.
Клиент использует единственный [контракт 1.0.0/agreed](../contracts/api-v1.yaml).

## Запуск

Из соседнего каталога `api/` с установленным окружением:

```bash
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

Открыть **http://127.0.0.1:8000/**. API обслуживает `ui/index.html` на `/`
и `ui/assets/` на `/assets/`; отдельный UI-сервер и npm не требуются.
Установку закреплённых зависимостей описывает [README API](../api/README.md).
Не использовать `--reload` во время создания. При другом порте настройки origin API
и адрес запуска должны совпадать; UI не содержит жёстко заданного порта.

## Использование

1. Выбрать номер ЕГЭ и при необходимости одну категорию. «Все категории» — по умолчанию.
2. Нажать «Найти задачи», просмотреть полные условия, рисунки, таблицы и ссылки.
3. Добавить задачи, листать выдачу, удалить лишние или менять порядок кнопками.
   Подборка не теряется при поиске. Дубли ID запрещены, максимум 100 пунктов.
4. Нажать «Создать работу» без ввода имени/пути. Пока идёт один запрос,
   создание и редактирование подборки заблокированы; поиск остаётся доступен.
5. Нажать «Скачать для ученика (PDF/ZIP)», после получения — «Сохранить файл».
   При приложениях нужен ZIP целиком, PDF отдельно предназначен для просмотра.
6. Ответы и источники получить отдельными кнопками «Для преподавателя».

Блок 19–21 — один пункт. Подборка хранится только в открытой странице, а готовые
материалы/метаданные сохраняются API после перезапуска до ручной очистки.
После изменения порядка прежние материалы явно отмечаются как предыдущая подборка.
Получение Blob означает получение тела файла, не подтверждение сохранения на диск.

Подтверждённый отказ снимает блокировки и разрешает явный повтор. При потере
подтверждения показаны «Результат не подтверждён» и «Предыдущая работа могла быть создана»;
доступно только явное «Создать новую работу», без автоматического JS-повтора/polling.

## Проверки из каталога UI

Используется существующее окружение API, установленные pytest/Playwright/yaml/jsonschema.
Все тесты самостоятельно запускают настоящий API для статической выдачи и отдельное
временное хранилище; default `api/var/works` не очищается и не используется тестами.

```bash
../api/.venv/bin/python -m pytest -q -m controlled
../api/.venv/bin/python -m pytest -q -m real_local
../api/.venv/bin/python -m pytest tests/test_ui.py -q -s -m live_ui
../api/.venv/bin/python -m ruff check tests
```

- `controlled`: настоящий UI/браузер, API-ответы и ресурсы подменены перехватами.
- `real_local`: настоящий UI/API/Bank/export_pdf/Chromium; подменён только внешний
  HTTP-источник фиксированными сырыми страницами из тестов API. Включены сравнение
  условий с sources/PDF, все шесть операций, ошибки и обрыв файлового TCP.
- `live_ui`: настоящий сайт и все компоненты, без подмен HTTP-ответов, Bank или экспортёра.
  Для намеренного транспортного отказа используется отключение соединения либо
  побайтовый TCP relay, который не создаёт ответы API.

По умолчанию pytest запускает только `controlled`; live-проверки не выдаются за пропуски
или автоматический fallback. Журналы, скачанные материалы, изображения PDF и скриншоты —
в игнорируемом `.test-artifacts/runs/`. Они являются локальными свидетельствами,
не статикой приложения и не кандидатами в общий коммит.

Для Firefox: `../api/.venv/bin/python -m playwright install firefox`, затем
`../api/.venv/bin/python -m pytest -m controlled --ui-browser=firefox --maxfail=1`.
В текущем окружении Firefox скачан, но запуск завершается `Could not find profile folder`;
проверка этого браузера **не пройдена**.

## Открытая общая граница

Отдельный воспроизводитель:

```bash
../api/.venv/bin/python -m pytest tests/test_ui.py -q -s -m boundary_probe
```

Это **известная непройденная проверка**, не xfail/skip. При обрыве TCP до заголовков
Chromium 153 в наблюдавшихся прогонах повторил HTTP-запрос внутри одного Fetch:
один браузерный request-event, но две серверные работы, UI получил 201.
Отдельный обрыв после заголовков до полного JSON корректно даёт unknown без повтора.
UI-код не содержит retry; полной гарантии A-02/A-07 для первого случая пока нет.
Вопрос передан API/человеку, API-код и контракт не изменялись.
