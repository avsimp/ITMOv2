# Контракт этой фичи

Единственный основной контракт UI/API:
[homework/contracts/api-v1.yaml](../../../../contracts/api-v1.yaml).

Статус — **согласован** (`agreed`), версия `1.0.0`.
Команда UI подтвердила A-01–08, все 6/6 условий и готовность принять контракт;
пользователь принял согласованное поведение. Переход от draft.2 меняет только
версию и статус: поля, форматы и поведение сохраняются.
Этот каталог содержит только ссылку; второй редактируемой схемы здесь нет.
Запросы, ответы, статусы, ошибки, MIME и примеры изменяются в общем YAML.
Дальнейшие изменения общего контракта согласуются обеими командами до реализации.
Runtime OpenAPI будущего FastAPI проверяется на соответствие общему файлу,
но не используется как независимый редактируемый источник договорённостей.
