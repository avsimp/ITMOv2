# Реализация API: фактические проверки и ограничения

**Этап**: API-компонент по контракту `1.0.0/agreed`; запуски 28.10.2026.
UI отсутствует, его файлы не создавались командой API. Полная приёмка UI/API не объявляется.
Пользователь отдельно подтвердил отсутствие редактирования UI и разрешил коммит API
с явным сохранением незавершённого LIVE-UI.

## Реализовано

Шесть операций общего контракта: категории, поиск, task-bound ресурсы, создание,
метаданные, материалы работы. Существующие Bank/export_pdf вызываются напрямую,
а не копируются. Поиск отделяет ответы, HTML-проекция не мутирует источники.
Все публичные URL серверные, каталог каждого экспорта отдельный, name не является путём.
Готовность публикуется последним work.json; файлы читаются с диска после перезапуска.
JSON-ошибки, прямой POST без redirect и нативные файловые Range-ветви реализованы.

Общий код ДЗ 3 изменён только в согласованной точке: добавлен подкласс
OutputConflictError(SourceError), два прежних отказа от перезаписи получили этот тип.
Сообщения и интерфейсы MCP не менялись. PDF-генератор, нумерация и ZIP-логика не переписывались.

macOS, Python 3.14.4; FastAPI 0.162.0, Starlette 1.10.0, Uvicorn 0.54.0,
AnyIO 4.15.1, Pydantic 2.14.1, HTTPX 0.28.1, MCP 1.30.0,
Playwright 1.63.0/установленный Chromium, PyMuPDF 1.28.2;
API pytest 9.2.0, Ruff 0.17.3. Зависимости закреплены в requirements-api.txt/requirements-dev.txt.

### CONTROLLED

Настоящие HTTP-обработчики на FakeBank/управляемом экспортёре либо файлах-фикстурах.
Проверены типы/границы/query-параметры, 422/400/405/415/404/409/500/502/504,
отсутствие путей/traceback, отдельные файлы и MIME, отсутствие исходных ответов в Task/Work,
публикация только после комплектности, незавершённые/повреждённые маркеры, symlink,
сериализация экспортов, чтения во время ожидания, отмена ожидания и сохранение маркера.
Тестовая статика проверяет границу `/`/`assets`, не является реальным компонентом UI.
Проверены реальный FileResponse и все согласованные Range-ветви, включая JSON 404
до FileResponse при плохом Range и отсутствующем файле. Источники ошибок выводятся безопасно.

Эти проверки не доказывают работу сайта или рендеринга. Код проверок консолидирован:
ошибки банка находятся в test_bank_http.py, проверки создания/публикации/учительских файлов
и перезапуска — в test_works.py; структура тестов не является дополнительным контрактом.

### REAL-LOCAL — настоящий локальный стек, внешний источник подменён

В tests/source_fixture.py подменяется только HTTP к источнику. Исходные Bank.fetch,
categories/search/get/парсер и export_pdf работают вместе с HTTP-обработчиками,
настоящим Chromium/PyMuPDF и файловой системой.

Проверены работы на **1, 3 и 100 уникальных ID**: count и порядок меток внутри PDF,
нумерация пунктов, полный блок 19–21 и три ответа одним пунктом, A4, рисунок/таблица,
PDF без приложений и ZIP с приложениями, названия по позициям, исходные байты,
original tasks и SHA-256 в sources, относительные ссылки после распаковки в другой каталог.
Проверены отсутствующая задача и неполная игра с явным 502 без публичной частичной работы.

Отдельный настоящий Uvicorn/TCP-прогон читает комплект после реального перезапуска
процесса. Внешний HTTP в этом дочернем процессе недоступен через proxy 127.0.0.1:1;
известные материалы при этом доступны. Клиент прекращает чтение после первых 64 байт,
затем повторно получает сохранённый файл. Один материал удаляется, остальные доступны.
Это не проверка живого сайта и не браузерный LIVE-UI.

## Ограничения и оставшиеся задачи

Настоящие ui/index.html и ui/assets на этапе API отсутствуют. Поэтому LIVE-UI,
проверка браузерных pending/unknown/redirect/Blob состояний и совместная финальная
приёмка **не выполнялись**. Успех временной статики или FakeBank не выдан за LIVE-UI.
В задачах эти зависимости и итоговые gates остаются открытыми, хотя независимые
API-контрактные и MCP-проверки текущей реализации уже выполнены успешно.
Отмечены выполненными T001–T046 (**46/54**); T047–T054 — настоящий UI-прогон
и финальные совместные проверки/сдача — оставлены открытыми. README и quickstart
для текущей API-части уже обновлены, но это не закрывает финальный UI smoke в T053.

Не добавлены фоновые задания, БД, авторизация, история, автоудаление, идемпотентность
или восстановление потерянной работы. При падении процесса до маркера каталог
непубличен и удаляется вручную. После потери ответа возможен дубль при явном новом POST.
Изменений контракта 1.0.0 и исходных четырёх снимков не потребовалось.
