Открыты T044 (весь случай потери связи), T047 (полная готовность US3),
T048 (итоговая общая gate после US3, хотя отдельный тест форматов выполнен),
T049 (Firefox), T050 (общие предпосылки), T052 и T053 (полная приёмка/финальная сдача).
Запись блокера не закрывает эти задачи. Остальные задачи подтверждаются кодом,
раздельными прогонами и журналами в [ui-verification.md](ui-verification.md).

Требуется согласование API/человека по B-01: транспортный повтор Chromium ниже Fetch
создал две серверные работы до первого полученного ответа. Нельзя единолично добавить
идемпотентность или ослабить требование отсутствия повтора в принятом контракте.
Также требуется доступный Firefox для плановой браузерной приёмки.

Готовые файлы можно проверять и фиксировать только с явным сохранением этих ограничений;
завершение полного этапа не заявляется. Коммит выполняет API-чат после проверки
и подтверждения, что UI не редактирует файлы.
